2. **Why is it useful to visualize data before analysis?  
    **
3. **Describe what happens during an 'outer' merge in Pandas.  
    **
4. **What role does the 'index' play in a DataFrame, and when might you want to reset it?  
    **


** Solution Key**


1. Renaming ensures consistent column names across datasets, which is critical for accurate merging.  

2. Visualizing data helps identify trends, patterns, and potential issues such as outliers or missing values.  

3. An outer merge returns all records from both datasets, filling in NaNs where there are no matches.  

4. The index is a label-based identifier for rows; resetting it is useful when the index is no longer meaningful or after filtering.
