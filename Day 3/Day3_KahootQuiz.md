Lesson 5: Linear Algebra Quiz
1. What is the difference between a scalar and a vector in linear algebra?
a) A scalar has both magnitude and direction, while a vector has only magnitude.
b) A scalar is a single numerical value, while a vector is an ordered collection of numerical values.
c) Scalars and vectors are interchangeable in all mathematical operations.
d) A scalar is always a matrix with multiple rows and columns.

2. What does the transpose of a matrix represent?
a) A matrix obtained by swapping its rows and columns.
b) A matrix obtained by multiplying all elements by −1.
c) A matrix obtained by calculating the inverse of each element.
d) A matrix containing only the diagonal elements of the original matrix.

3. What is an "affine transformation" in the context of linear algebra?
a) A transformation that always passes through the origin.
b) A linear transformation followed by a translation (shift).
c) A transformation that only involves scaling.
d) A transformation that only involves rotation.

4. What is an "eigenvector" in linear algebra?
a) A vector that, when multiplied by a matrix, changes its direction significantly.
b) A nonzero vector whose direction remains along the same line when a linear transformation is applied, scaled by an eigenvalue.
c) A scalar value that defines the magnitude of a matrix.
d) The inverse of a matrix.

5. What does "eigendecomposition" involve?
a) Breaking down a vector into its component parts.
b) Decomposing a matrix using its eigenvectors and eigenvalues.
c) Multiplying two matrices together.
d) Calculating the determinant of a matrix.

6. Which of the following is a key application of eigendecomposition in machine learning?
a) Simple arithmetic operations.
b) Principal Component Analysis (PCA).
c) Basic data visualization.
d) String manipulation.

7. What is the purpose of the "determinant" of a matrix?
a) It indicates the number of rows in the matrix.
b) It determines if a square matrix has an inverse and represents the signed scaling factor of the linear transformation.
c) It specifies the data type of the matrix elements.
d) It is used to transpose a matrix.

8. What is Singular Value Decomposition (SVD)?
a) A method to calculate the sum of matrix elements.
b) A powerful matrix factorization technique with applications in dimensionality reduction and data compression.
c) A process of adding two vectors.
d) An operation to find the maximum value in a matrix.

9. The "Moore-Penrose Pseudoinverse" is particularly useful for what kind of matrices?
a) Square matrices only.
b) Invertible matrices only.
c) Non-square or singular matrices that do not have a traditional inverse.
d) Identity matrices.

10. What does the "Trace Operator" of a square matrix calculate?
a) The product of its diagonal elements.
b) The sum of its diagonal elements.
c) The maximum value in the matrix.
d) The sum of all elements in the matrix.
